This is a starter post for the `eleventy-prose-blog` template. It exists to show off the formatting the template supports, so you can delete it once you've seen what's available.

This template is tuned for long-form prose: essays, reviews, journal entries. The type is set for reading rather than scanning. It also treats single line breaks as intentional rather than collapsing them, which matters for writing that uses line breaks for pacing — like this:
Three lines,
each its own beat,
rendered exactly as typed instead of being run together.

You can still reach for the usual tools when a post needs them — a footnote,[^1] a [link](https://www.11ty.dev), a block quote:

> A quotation sits apart from the body text, set off enough to read as someone else's words.

Replace this post — and the others in `content/posts/` — with your own writing whenever you're ready.

[^1]: Footnotes work here too, for citations or asides that would break the flow of a sentence.
